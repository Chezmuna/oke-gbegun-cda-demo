# Oke-Gbegun CDA Portal: demo

Static demo (no database, no server). All residents and figures are sample data modelled on the estate's ledger totals.

## Deploy on Vercel (new project)
1. Put these files in a new GitHub repository (or drag the folder onto vercel.com/new).
2. Framework preset: "Other". No build command and no output directory are needed.
3. Optional: add the domain demo.chezmunadigital.com.ng under Settings -> Domains.
`vercel.json` tells search engines not to index the demo. Share the link only with the CDA.

## Before showing it
- Click "Reset demo" to return to the starting state.
- The payment screens are simulations; no gateway is contacted and no money moves.
- Do not replace the sample data with the real ledger on a public link.
